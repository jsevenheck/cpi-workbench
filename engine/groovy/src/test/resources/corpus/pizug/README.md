# Community script corpus

Scripts and test data from [pizug/cpi-groovy-examples](https://github.com/pizug/cpi-groovy-examples)
(commit bae8549e5276b6d853478dc65516d057fd457085 Tue Dec 19 17:49:16 2023 +0300). The Groovy scripts are MIT licensed (see LICENSE);
only the scripts and their input/expected files are copied, no SAP code.

`GroovyCorpusTest` runs every folder on both Groovy engines and compares the result with the
`expected.*` files. Known version differences are listed in the test.
